## 📋 What is Hype ERP?

**Hype ERP** is a complete **desktop ERP + billing software** built with Python & Tkinter, developed by **Nexuzy Lab** and led by **David (DevilOne)**.

It runs fully **offline**, syncs to **Firebase** when online, generates **GST-compliant PDF invoices**, and includes a full suite of **20 enterprise modules** covering billing, accounting, inventory, HR, payroll, CRM, manufacturing, and more — all in one system.

Every invoice, bill, and PDF generated by this software is permanently branded **Hype ERP** — this branding cannot be removed.

---

## ✨ Complete Feature List

### 🧾 Core Billing

- GST-compliant invoice generation (SGST, CGST, IGST)
- Barcode / SKU product lookup during billing
- Walk-in and named customer support
- Multiple payment methods — Cash, Card, UPI, Credit
- Invoice PDF export with permanent Hype ERP header/footer
- Auto invoice numbering with custom prefix (e.g. `INV-202506-0001`)
- Customer GSTIN capture on invoice
- Per-item GST rate on each invoice line
- Payment status tracking — Paid, Unpaid, Partial
- Invoice notes / remarks field
- Offline-first — all data stored in local SQLite database

---

### 📦 Inventory & Stock

- Add, edit, and delete products with full details:
  - Product name, barcode/SKU, category, category code, unit
  - Purchase price and selling price
  - Stock quantity and minimum stock threshold per product
  - GST rate and HSN code
- Auto low-stock alerts — products below minimum threshold highlighted in red/yellow
- Dead stock analysis — detects items unsold for 90+ days
- Quick Price Adjust — change selling price of any product directly from the product list
- Quick Restock — add stock quantity in one click
- Stock adjustment and purchase price tracking
- Custom product categories — create and manage your own category list
- Auto GST rate population when a category is selected
- Auto HSN code population from category-to-HSN mapping
- Immediate Firebase sync when a new product is saved

---

### 💰 GST & Tax Configuration

- 20 pre-loaded GST rate profiles:
  Cosmetics, Grocery, Drinks, Electronics, Clothing, Food & Beverage, Dairy,
  Pharmaceuticals, Automotive, Furniture, Books, Education Services, Healthcare,
  Agriculture, Construction, Metals, Chemicals, Tobacco, Services, Petroleum Products
- Custom GST rate manager — Add, Edit, Delete category-wise SGST, CGST, IGST rates
- GST rates saved to local database — persist across sessions
- Full Tax / GST ERP module for advanced tax management

---

### 🗂️ HSN Code Management

- 20 default HSN codes pre-mapped to standard product categories at startup

- Auto-fills HSN code when a product category is selected during product creation

---

### ☁️ Firebase Cloud Sync & Backup

- Bi-directional sync between local SQLite and Firebase Firestore
- Offline-first — works fully without internet; syncs when connection is available
- Auto-restore — if local database is blank on first launch, automatically pulls all data from Firebase
- One-click full sync and one-click cloud backup
- Firebase Settings GUI — configure Firebase from inside the app without editing config files
- Encrypted service account key (`.enc` file) — Firebase credentials are never stored as plaintext
- Cloud data scoped per store under `stores/{store_id}/` path
- Firebase Deep Dashboard — advanced Firestore viewer with manual sync controls
- Firebase Upload Manager — bulk data upload for large datasets
- Firebase CLI sync tool — run sync without launching the GUI (useful for scheduled backups)

---

### 🏪 Store & Multi-Store Management

- Multi-store support — each store has name, address, phone, email, GSTIN, owner name, state code, and logo
- State code configuration for correct intra/inter-state GST calculation (default: 29 Karnataka)
- Custom invoice prefix per store
- Active/inactive store switching

---

### ⚙️ Settings

- Shop name
- Owner name
- Shop address
- Phone number
- GSTIN
- Invoice prefix
- State code
- Firebase configuration (GUI-based, no file editing required)

---

### 🔐 Users & Access Control

- Multi-user login with username and password
- Role-based access — Admin, Manager, Cashier
- SHA-256 hashed passwords (auto-migrated from plain text on first run)
- Login runs in background thread — UI never freezes
- Firebase-fallback login — if user not found locally, restores from Firebase automatically
- Windows single-instance lock — prevents opening two copies of the app simultaneously

---

### 🛠️ Setup & Installation

- Auto-installer (`auto_install.py`) — checks and installs missing dependencies at startup
- Works as a standalone Windows `.exe` (built with PyInstaller + Inno Setup)
- Database stored at `%LOCALAPPDATA%\HypeERP\` in EXE mode for safe multi-user Windows installs
- Crash logs written automatically to `%LOCALAPPDATA%\HypeERP\hype_erp.log`
- Silent database schema migration on every startup — safe upgrades without data loss

## 🚀 Getting Started

### Requirements

- Python 3.8+
- Windows 10 / 11 (recommended)
- Internet connection (optional — for Firebase sync)

### Installation

```bash
git clone https://github.com/david0154/hype-billing-system.git
cd hype-billing-system
python auto_install.py   # installs all required packages automatically
python main.py
```

### Default Login

| Username | Password  | Role  |
|----------|-----------|-------|
| admin    | admin123  | Admin |

> Change the default password immediately after first login.

### Firebase Setup (Optional)

1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Download `serviceAccountKey.json`
3. Place the file in the project root folder OR use the in-app **Firebase Settings** screen
4. The app will automatically encrypt the key and sync data to Firestore
